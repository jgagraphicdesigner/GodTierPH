BUILD GUIDE

Alithea

Disruption build direction for entering enemy groups, stunning, freezing, and escaping.

All BuildsGuild League Strategy

Role

  • Use Gravity Well for the 1-second stun.
  • Use Glacial Stomp for the 1-second freeze.
  • Enter enemy groups only when the team can follow up.

Build Direction

  • Build more survivability with VIT + Goibne Set if possible.
  • Prioritize living long enough to cast and exit.
  • Use defensive gear when assigned to roam.

Guild Notes

  • Enter, use Glacial Stomp + Gravity Well, then get out.
  • Reposition immediately after the combo.
  • Assist TOP or BOTTOM when assigned.
